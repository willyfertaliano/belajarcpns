# Belajar CPNS v2.0

Aplikasi Android latihan CPNS yang dapat dibuild melalui GitHub Actions dari HP.

## Fitur v2.0
- Bank 100 soal latihan contoh: 34 TWK, 33 TIU, 33 TKP
- Simulasi campuran mengambil 100 soal
- Timer 100 menit untuk simulasi 100 soal
- Timer otomatis untuk latihan kategori (1 menit/soal)
- Nilai 0–100
- Jumlah jawaban benar
- Poin latihan
- Pembahasan setelah menjawab
- Soal diacak
- Offline setelah APK terpasang

## Build
1. Upload seluruh isi project ke repository GitHub.
2. Buka Actions.
3. Pilih Build APK Belajar CPNS.
4. Run workflow.
5. Download artifact BelajarCPNS-debug.
6. Ekstrak dan install `app-debug.apk`.

Catatan: bank soal adalah contoh latihan buatan aplikasi, bukan soal resmi seleksi CPNS. Ketentuan, jumlah soal, bobot, dan passing grade seleksi dapat berubah sesuai kebijakan resmi.
